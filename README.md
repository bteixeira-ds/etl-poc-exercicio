Minha primeira POC em Engenharia de Dados!

Desenvolvi um pipeline ETL completo usando Python para provar que é possível:
- Extrair dados de um CSV
- Limpar e transformar os dados
- Carregar no PostgreSQL
- Validar qualidade e gerar logs

Resultado:
- Pipeline funcional do início ao fim
- Dados validados antes de ir para o banco
- Logs para rastrear cada etapa
- Sem duplicatas (UPSERT)

Essa POC me ajudou a entender na prática como a engenharia de dados resolve problemas reais!
